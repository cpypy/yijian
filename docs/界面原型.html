Attention Is All You Need

Ashish Vaswani, Noam Shazeer, Niki Parmar, Jakob Uszkoreit, Llion Jones, Aidan N. Gomez, Łukasz Kaiser, Illia Polosukhin
NeurIPS 2017 · arXiv:1706.03762 · 译文由 deepseek-chat 生成 · 已校 3 段

Abstract
01The dominant sequence transduction models are based on complex recurrent or convolutional neural networks that include an encoder and a decoder. The best performing models also connect the encoder and decoder through an attention mechanism. We propose a new simple network architecture, the Transformer, based solely on attention mechanisms, dispensing with recurrence and convolutions entirely.
02Recurrent models typically factor computation along the symbol positions of the input and output sequences. Aligning the positions to steps in computation time, they generate a sequence of hidden states ht as a function of the previous hidden state ht−1 and the input for position t.
03An attention function can be described as mapping a query and a set of key-value pairs to an output, where the query, keys, values, and output are all vectors. The output is computed as a weighted sum of the values, where the weight assigned to each value is computed by a compatibility function of the query with the corresponding key [1]

摘要
01主流的序列转换模型都建立在包含编码器与解码器的复杂循环或卷积神经网络之上。表现最好的模型还会通过注意力机制把编码器与解码器连接起来。我们提出一种全新的简单网络架构——Transformer，它完全基于注意力机制，彻底摒弃了循环与卷积。
02循环模型通常沿输入序列与输出序列的符号位置来分解计算。将位置与计算时间步对齐后，它们会生成一个隐藏状态序列 ht，其取值是前一隐藏状态 ht−1 与位置 t 处输入的函数。
03注意力函数可以描述为：将一个查询（query）与一组键值对（key-value）映射为输出，其中查询、键、值和输出都是向量。输出是各个值的加权和，每个值所分配的权重由查询与相应键的相容性函数计算得到[1]。
