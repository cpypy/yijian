# 译见 v0.1.0

第一个可用版本。输入 arXiv ID，得到中英对照的论文阅读界面，以及一份 ctex 重编译的中文 PDF。

## 能做什么

**取源 → 分段 → 翻译 → 编译**
从 arXiv 拉 LaTeX 源码，逐段翻译（公式、引用、标签用占位符保护），再用 ctex 重编译成中文 PDF。公式、图表编号、参考文献都留在原位。

**双语阅读器**
左英文右中文，同一行对齐。支持原文 / 对照 / 译文三种模式、文内搜索、段落点击高亮、阅读进度记忆。

**公式与引用**
`[[MATH_n]]` 用 KaTeX 渲染成真公式；引用渲染成 chip，点开显示本地解析的文献信息（作者 / 标题 / 出处），不联网。

**术语表**
设置里维护 `英文,中文` 对照表，会写进引擎的 `glossary.yaml`，**影响实际翻译**而不只是显示；阅读时高亮命中术语。

**笔记**
每段可写批注，自动保存，随论文一起管理。

**文库**
集合树（多级）、标签、搜索、阅读进度。打开旧论文直接回到上次读到的位置。

**发现**
alphaXiv 全站热榜（近 7 天），一键译入或收藏。

**任务队列**
连续提交多篇会排队执行，可清空；每篇完成显示 tokens 与耗时。

**自带模型**
设置里填 Base URL / 模型 / API Key（任何 OpenAI 兼容端点）。没有 Key 时用占位译文，链路照样能跑通。

## 安装

从 Release 下载对应安装包：

| 平台 | 文件 |
|---|---|
| Windows 10/11 | `Yijian_0.1.0_x64-setup.exe` |
| macOS (Apple Silicon) | `Yijian_0.1.0_aarch64.dmg` |
| Linux (Debian/Ubuntu) | `Yijian_0.1.0_amd64.deb` |

安装包**未签名**：

- Windows 会弹 SmartScreen，点「更多信息 → 仍要运行」
- macOS 需在「隐私与安全性」里允许

## 第一次使用

1. 打开应用，点右上角 ⚙
2. 填 Base URL、模型名、API Key（例如 `https://api.deepseek.com/v1` / `deepseek-chat` / `sk-...`）
3. 回工作台输入 `1706.03762`，点开始
4. 跑完自动进入阅读器

首次编译会用安装包预置的 TeX 宏包缓存（约 33 MB，覆盖 6 篇论文用到的包）。遇到没预置的宏包，tectonic 仍会联网补下载。

## 已知限制

- **未签名**：见上。
- **PDF 预览**：目前用系统默认阅读器打开，应用内还没嵌 PDF 视图。
- **引用卡**：只解析论文自带的 `.bbl`，命中率取决于 bib 是否完整（实测约 77%）。
- **发现**：alphaXiv 接口没有官方文档，属于社区逆向，可能随时失效。
- **全文搜索**：目前搜的是标题/作者/arXiv ID，还没做段落级全文索引。
- **Linux**：只提供 `.deb`，AppImage 打包在 CI 上不稳定，暂未提供。
